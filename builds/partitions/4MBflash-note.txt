There is no way that ehRadio will build and still fit into a default 1.31 MB space allowed
in the default 4MB partition scheme, so first try 4MBflash-OTA.csv

Some builds (depending on your peripherals and options like display model, MQTT, etc)
will eat into the maximum allowed app space (1.8 MB).

Please note that both special partition schemes are untested with recent versions of ehradio.
SPIFFS must be around 400KB to reliably run Search and Curated Lists and file updates.

But if you really must tinker, try building with 4MBflash-SPIFFS.csv first with #define CORE_MONITOR
in your myoptions.h file.  This will show SPIFFS space used and free.

And although that build breaks OTA, you will still have a very usable ehRadio.
